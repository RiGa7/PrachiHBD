# 📸 Drop Your Sister's Photos Here!

Place your sister's photos in this folder (`d:\hbd\public\photos\`).

Recommended names:
- `photo1.jpg` (or .png / .webp) -> Funny / Cringe / Derp face
- `photo2.jpg` -> Baby photo / 2010 throwback
- `photo3.jpg` -> Cute / Aesthetic photo
- `photo4.jpg` -> "Caught in 4k" / Drama queen photo
- `photo5.jpg` -> Sibling photo with you
- `photo6.jpg` -> Recent cool picture

You can add any format (.jpg, .jpeg, .png, .webp).
You can also customize the captions and photos list in `src/birthdayConfig.ts`!
